LITTLE TRACK GUIDE

Quick user manual.

Parent / guardian

  1. Open Profile and choose Parent / Guardian.
  2. Enter demo profile details and accept the prototype consent statement.
  3. Choose Upload Photo or Use Camera. Allow camera permission if prompted.
  4. Preview the image before submitting a demo record.
  5. Review the local record list. This demo does not send an SMS or contact a doctor.

Doctor

Switch to Doctor in the demo portal to view sample records saved in this browser. Real doctor access requires secure authentication and a backend.

Technical integration

ESP32-CAM streaming, backend image processing, a trained ML model, secure database and SMS notifications are not connected in this starter website.

Do not use this prototype to diagnose or rule out jaundice. Follow a qualified clinician's advice and appropriate bilirubin testing.
